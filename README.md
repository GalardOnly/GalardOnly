Previsão de Casos de Dengue — Ourinhos/SP (TCC)
Modelo preditivo de surtos de dengue no município de Ourinhos/SP integrando dados epidemiológicos do SINAN com dados climáticos do INMET. O projeto demonstrou que a memória epidemiológica — e não o clima isolado — é o fator determinante para prever surtos.
Resultados:
Variáveis climáticas isoladas explicaram apenas 32% da variação de casos (R² = 0,07 no modelo puramente climático)
Integração com microdados do SINAN elevou para R² = 0,73 e MAE de 48,77 casos por semana
Erro médio de apenas 13 casos/semana em 2023 (dentro do padrão histórico)
Limite identificado em 2025, o surto mais grave já registrado em Ourinhos (10.041 casos), evidenciando a fronteira de confiabilidade do modelo e apontando para trabalhos futuros com dados de sorotipo e cobertura vacinal
Tecnologias: Python, Pandas, Scikit-Learn, Random Forest, Matplotlib, Seaborn, Streamlit  
Repositório: github.com/GalardOnly/previsao-dengue-ourinhos  
Dashboard interativo: previsao-dengue-ourinhos.streamlit.app
